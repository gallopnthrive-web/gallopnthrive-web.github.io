# Gallop & Thrive Apps

Official website and support resources for apps published by Gallop & Thrive Ltd.

## Handheld Accountants

Handheld Accountants is a private receipt scanner and expense-recording app for iPhone and iPad.

It helps users:

- Scan receipts using the device camera
- Extract merchant, date, total, currency and tax information
- Organize receipts using separate profiles
- View monthly spending totals by currency
- Export receipt records as CSV and PDF
- Store receipt information locally on the device
